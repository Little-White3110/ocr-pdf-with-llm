使用指南

PDF OCR Web 是一个基于 Web 的 PDF OCR 处理工具，支持中文识别和大纲生成

项目介绍 安装指南 使用教程 配置说明 常见问题

项目介绍

PDF OCR Web 是一个功能强大的 PDF OCR 处理工具，具有以下特性：

text_fields OCR 文字识别

支持中英文混合识别，使用 LSTM 神经网络引擎，识别准确率高。

auto_awesome LLM 大纲生成

集成大语言模型，自动分析文档内容生成目录大纲，支持嵌入到 PDF。

cloud_upload 批量处理

支持多文件批量上传和处理，自动排队处理任务。

dark_mode 深色模式

支持亮色/深色主题切换，保护您的眼睛。

安装指南

系统要求

  • Python 3.10 或更高版本
  • Tesseract OCR（包含中文语言包）
  • Ghostscript（可选，用于高级图像处理）

Windows 安装

安装 Tesseract OCR

从 UB Mannheim 下载安装程序，安装时选择中文语言包（chi_sim）。

运行启动脚本

双击 start.bat 文件，脚本会自动安装依赖并启动服务。

访问应用

浏览器会自动打开 http://localhost:8080，如果没有自动打开，请手动访问。

Linux/macOS 安装

安装 Tesseract

# Ubuntu/Debian
sudo apt install tesseract-ocr tesseract-ocr-chi-sim

# macOS
brew install tesseract tesseract-lang

运行启动脚本

chmod +x start.sh
./start.sh
注意： 如果 Tesseract 未添加到系统 PATH，需要在 config.py 中指定路径。

使用教程

上传文件

选择文件

点击上传区域选择 PDF 文件，或直接拖拽文件到上传区域。支持多文件批量上传。

配置选项

在弹出的对话框中配置处理选项：

  • 生成大纲 - 使用 LLM 自动生成文档大纲
  • 大纲生成模式 - 自动总结或读取目录页
  • 嵌入大纲到 PDF - 将大纲嵌入到 PDF 书签

开始处理

点击"确认上传"按钮，文件会自动加入处理队列。

下载结果

处理完成后，任务卡片会显示两个下载按钮：

  • PDF - 下载 OCR 处理后的 PDF 文件（包含文本层）
  • 文本 - 下载清理后的纯文本文件（无多余空格）

批量操作

使用任务列表上方的复选框选择多个任务，然后使用批量操作按钮：

  • 批量下载 - 下载所有已完成的任务（打包为 ZIP）
  • 批量删除 - 删除选中的任务

配置说明

LLM 配置

点击右上角设置按钮，配置以下信息：

key API Key

LLM API 密钥，支持 OpenAI、DeepSeek 等兼容接口。

link Base URL

API 基础地址，例如：

  • DeepSeek: https://api.deepseek.com/v1
  • OpenAI: https://api.openai.com/v1
  • 本地部署: http://localhost:11434/v1

smart_toy 模型

使用的模型名称，例如 deepseek-chat、gpt-4 等。

存储管理

在设置页面可以查看存储信息并清理文件：

  • 清理过期文件 - 删除超过 30 分钟的文件
  • 清理全部文件 - 删除所有上传和输出的文件
提示： 系统会每 30 分钟自动清理超过 30 分钟的文件。

常见问题

help OCR 识别率不高怎么办？

请确保已安装中文语言包（chi_sim）。对于扫描质量较差的 PDF，可以尝试提高 DPI 设置或使用更高质量的扫描件。

help 处理速度很慢怎么办？

OCR 处理是 CPU 密集型任务，处理时间取决于 PDF 页数和图像质量。建议分批处理大型文档。

help 如何在另一台电脑使用？

复制整个项目文件夹到新电脑，确保安装了 Python 和 Tesseract，然后运行启动脚本即可。

help 支持哪些文件格式？

目前仅支持 PDF 文件。图片文件需要先转换为 PDF 格式。

help 中文之间有多余空格？

下载文本文件可以获得清理后的版本，中文字符间的多余空格已被移除。

help 如何修改端口？

修改启动脚本中的端口号： 

# 后端端口
python -m uvicorn main:app --host 0.0.0.0 --port 8000

# 前端端口
python -m http.server 8080
同时修改 frontend/app.js 中的 API_BASE 变量。
